# 📊 Amazon Sales Dashboard – Excel

## 📌 Project Overview

This project presents an interactive **Amazon Sales Dashboard built using Microsoft Excel**.

The dashboard transforms raw sales data into meaningful business insights through data cleaning, analysis, visualization, and interactive filtering.

The main goal of this project is to help stakeholders quickly understand **sales performance, trends, product categories, and geographical performance**.

---

## 🎯 Business Questions

This dashboard was designed to answer the following questions:

- What are the overall sales performance and key KPIs?
- How do sales change over time?
- Which product categories generate the highest sales?
- Which states/locations contribute the most to total sales?
- Which categories or locations may require further attention?
- What are the main sales trends and patterns?

The dataset was prepared and organized before building the dashboard.

The preparation process included:

- Checking the dataset for inconsistencies
- Cleaning and formatting the data
- Preparing fields for analysis
- Organizing the data for Pivot Tables
- Creating the required calculations and KPIs

---

## 📊 Dashboard Features

The dashboard provides an interactive view of the sales data through:

- KPI Cards
- Sales Trend Analysis
- Category Performance
- Geographical Sales Analysis
- Interactive Slicers
- Pivot Charts
- Dynamic Filtering

Users can interact with the dashboard using the available slicers to explore different parts of the dataset.

---

## 💡 Key Insights

Some of the main insights identified from the analysis include:

- **California** recorded the highest sales among the analyzed states.
- Sales showed noticeable increases during **November and December**.
- Different product categories contributed differently to overall sales performance.
- The dashboard makes it easier to identify sales trends and compare performance across different categories and locations.
